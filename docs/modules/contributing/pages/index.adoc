= How to Contribute
:description: Guide for contributing to Sabas OS.

Sabas OS follows a fork-based contribution model — the same workflow used by most professional open source projects.

== Quick Start

. Fork the relevant repo from `github.com/sabasos`
. Clone your fork locally
. Create a feature branch
. Make your changes
. Push to your fork and open a Pull Request to `sabasos:develop`

See xref:workflow.adoc[Development Workflow] for the full guide.
